# Metaverse 13 🌌

> **Enter a world designed around motion, atmosphere, and imagination.**

Metaverse 13 is a futuristic landing-page experience built with Next.js and Framer Motion. It focuses on immersive visual storytelling through animated sections, interactive world cards, glassmorphism, and responsive layouts.

## ✨ Experience

Metaverse 13 treats the landing page as an experience rather than a static collection of sections. Motion, typography, imagery, and layout work together to create a futuristic interface.

### Highlights

- 🌌 Immersive dark visual language
- 🎬 Scroll-triggered animations
- 🪐 Interactive world/realm cards
- 🧊 Glassmorphism-inspired UI
- 🧩 Reusable React components
- 📱 Responsive layouts

## 🎞️ Interaction Model

```text
Page Load
   ↓
Hero Experience
   ↓
Animated Sections
   ↓
Interactive Worlds
   ↓
Motion + Scroll Transitions
   ↓
Responsive Experience
```

## 🚀 Getting Started

```bash
git clone https://github.com/Karthik751-MR/project_metaverse.git
cd project_metaverse
npm install
npm run dev
```

Open `http://localhost:3000`.
